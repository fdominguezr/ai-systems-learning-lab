# Procedencia y límites — publicación #001 v2

Ejercicio de aprendizaje autocontenido preparado como material educativo con
asistencia de IA y revisión de resultados. Todos los ejemplos son sintéticos.

El programa utiliza funciones Python deterministas, no un modelo de lenguaje.
El clasificador candidato obtiene 4/4 aciertos sobre cuatro ejemplos iniciales
y 3/6 sobre seis contrapruebas diseñadas posteriormente para detectar errores.
Esas contrapruebas no representan un conjunto estadístico independiente ni
permiten estimar rendimiento real.

Los scripts no acceden a servicios externos, secretos ni datos personales.
La finalidad es mostrar una limitación de evaluación; este código no sirve
para autorizar operaciones ni como mecanismo de seguridad.

Se agradecen reproducciones, correcciones y nuevas contrapruebas mediante
issues del repositorio cuando esté publicado.
